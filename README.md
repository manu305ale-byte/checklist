# Checklist de Producción de Video

Landing page sencilla en HTML, CSS y JavaScript para controlar procesos de producción de video.

## Procesos incluidos

- Organización de proyecto
  - Organizar las carpetas en el escritorio.
  - Organizar el proyecto dentro de DaVinci Resolve.
- Cortes y audio
  - Limpieza inicial, cortes base y división por colores.
- Poner audio en stereo
- Edición
- Enviar audio
  - Exportar y compartir el audio para revisión o aprobación después de la edición.
- Renderizado
  - Verificar antes del render que el timeline esté dividido por colores.
- Subido a YouTube
  - Avisar por el grupo que el video está subido.
  - Llenar el Excel de control de producción como video finalizado.

## Uso

Abre `index.html` en el navegador. El avance se guarda automáticamente en `localStorage`.

## Despliegue rápido

Puedes subir esta carpeta a GitHub Pages, Netlify, Vercel o cualquier hosting estático.
